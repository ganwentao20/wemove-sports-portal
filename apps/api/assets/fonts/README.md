Noto Sans CJK SC Regular is embedded in generated order PDFs so English and Chinese product names and addresses remain legible. The unmodified font is distributed under the accompanying SIL Open Font License 1.1.

Source: https://github.com/notofonts/noto-cjk/blob/main/Sans/OTF/SimplifiedChinese/NotoSansCJKsc-Regular.otf

Deploy this directory with the API. `PDF_FONT_PATH` may select another Unicode font installed by the operator; its licensing and required glyph coverage must be checked before replacement.
