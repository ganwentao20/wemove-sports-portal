# 需求文档（④ · 整合版）目录大纲

## 2. 用户与使用场景（组长 + B）
- 2.1 角色画像：游客 / 注册消费者 / 经销商成员(企业) / 后台运营角色（商品/内容/订单客服/超管）
- 2.2 核心场景用例（UML 用例图 + 文字：浏览下单、经销商申请审核、RFQ 闭环、CMS 发布）
- 2.3 **合规边界（红线）**：产品面向儿童、账号与交易面向成年人；禁止儿童注册与数据收集

## 3. 功能需求（按门户分章，负责人=模块负责人）
- 3.1 前台品牌官网（A）：响应式、首页模块化、PLP 多维筛选、PDP（规格/图集/视频/对比≤4 款）、
  Play & Learn、全站搜索、支持下载、联系表单
- 3.2 B2C 用户中心（A）：注册/邮箱验证/登录找回、资料、地址簿、心愿单、购物车结算、订单追踪、售后申请
- 3.3 经销商门户（B）：资质申请与**审批状态机**（补件/通过/驳回）、授权目录与专属/阶梯价格展示、
  Quick Order、RFQ 版本化报价、PO 管理、私有资料签名下载
- 3.4 运营后台（D + C + 组长）：RBAC 角色权限矩阵表、PIM 商品/变体管理、价格规则管理、订单履约/退款
  状态机、经销商审核工作台、CMS/首页拖拽配置、SEO 与 301、审计日志、系统参数
- 每项编号规范：`F-PORTAL-01`… 附**优先级**（MoSCoW）+ 可演示验收点

## 4. 非功能需求（组长 + E）
- 4.1 性能：关键页首屏 ≤2.5s；100 并发稳定（附测试方法引用 ⑤）
- 4.2 兼容性：PC/Tablet/Mobile 三断点；**移动端禁止横向溢出**（含表格卡片化规则）
- 4.3 安全：游客不可越权获取经销商价；企业数据边界；bcrypt；后台二次认证；审计日志
- 4.4 SEO：SSR/ISR、meta/robots/sitemap、301 重定向策略
- 4.5 可用性与合规（成年人声明、隐私、内容合规）
