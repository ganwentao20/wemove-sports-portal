# 大模型辅助实践说明

姓名：倪依玲（组员 D，运营管理后台与内容模块）
使用的大模型：GitHub Copilot
一、使用情况概述
在本次实践中，我使用 GitHub Copilot 作为编程辅助工具，主要辅助运营管理后台（Admin UI）的页面开发与布局实现、CMS 富文本模块的配置与调试、媒体中心的资源管理与签名下载逻辑、联系工单的后台流转设计、SEO 与审计日志查看界面的搭建，以及系统操作手册的撰写。Copilot 提高了界面开发编码效率与文档编写速度，但所有页面代码、后台逻辑与操作手册均经本地运行验证、团队评审，并由组长合并到主分支。
二、具体辅助内容
Admin UI（运营管理后台界面）：辅助生成 admin 路由分组下的页面组件代码、后台导航布局与样式，加速各管理页面的组件拆分与调试。
CMS 与富文本：辅助编写富文本编辑器的集成代码与内容持久化逻辑，协助实现后台动态配置前台展示内容。
媒体中心：辅助编写图片与视频资源的上传、分类与签名下载相关代码，协助排查私有资源访问鉴权问题。
联系工单：辅助编写工单列表与状态流转的界面交互代码，协助设计后台工单管理流程。
SEO / 审计查看：辅助搭建 SEO 配置查看页面与审计日志列表界面的代码框架，协助理解相关字段的展示逻辑。
系统操作手册：辅助梳理操作手册的文字组织与格式排版，完成 docs/operation-manual.md 的撰写。
