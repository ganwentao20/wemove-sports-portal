# 大模型辅助实践说明

课程：软件开发实践 2（下午班 · 第 8 组）
项目：WEMOVE SPORTS 运动产品门户网站
姓名：龙祖怡（组员 E，测试与工程化）
使用的大模型：ChatGPT 系列辅助大模型
一、使用情况概述
在本次实践中，我使用ChatGPT作为学习与实践助手，主要辅助开发环境搭建与排障、工程流程理解、自动化测试与性能压测。AI 提高了排障与文档效率，但所有代码与测试结论均经本地验证、团队评审，并由组长合并到主分支。
二、具体辅助内容
1. 环境与工具：协助完成 Node.js 与 Docker 安装验证、镜像加速配置。
2. 工程流程与 CI：协助在 E1 中配合完成 Mailpit 与数据库集成端到端测试的本地验证。
3. 测试与压测（E2）：协助编写商品目录冒烟测试、运行 19 个端到端用例，并完成 100 并发压测，区分限流 429 防护与真实容量数据。
三、使用原则
1. 验证优先：先理解后执行，改动均经本地测试与组长 review 后合入。
2. 数据真实：报告数据来自实际运行结果，与 CI 一致，不伪造。
3. 独立思考：AI 用于解释概念与排查问题，最终结论由本人和团队负责。
四、总结
大模型在本项目中承担了助教与工具的角色，提升了排障与文档效率；项目的实现与质量结论由我本人和团队共同完成并负责
