## 一、议题与讨论要点

### 议题 1：确定组长及任务分工方式

讨论过程摘要：

1. 组员提出先确定组长，再由组长进行后续任务分配。
2. 没有成员主动担任组长，故采用群内“抽签助手”随机抓阄的方式确定组长。
3. 组长确定后，根据项目任务划分为 A、B、C、D、E 等不同分工，由成员认领对应任务。

结论：采用随机抽签方式确定组长，并由组长统筹项目后续分工。

### 议题 2：初步任务分工

讨论过程摘要：

1. 组长对项目进行了基本认知和初步分工。
2. 成员认领任务，确定分工。

结论：完成第一轮任务认领，成员开始按分工推进各自负责内容。

### 议题 3：项目协作与进度管理方式

讨论过程摘要：

1. 为统一项目进度管理，组长提出在 GitHub 上建立项目仓库，方便成员协作、提交和查看进度。
2. 没有成员提出无法使用 GitHub，一致通过。
3. 组长建立项目仓库，通过组员提供的邮箱邀请。

结论：优先使用 GitHub 作为项目协作和版本管理平台。
