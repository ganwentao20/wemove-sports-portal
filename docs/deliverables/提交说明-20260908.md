# WEMOVE 原网站重构课程提交说明

本包按 2026-09-08 当前工作区重新审查。项目口径是：保留原 `wemovetoy.com` 的品牌、栏目、交错图文版式和原图，在此基础上接入并完善文档要求的购买、企业采购和运营功能；不采用通用运动玩具商城作为新前端。

## 本轮确认与修正

- 需求文档升级为 v0.7，明确原网站优先、既有后端复用、完整中英文覆盖、统一登录和剩余外部依赖。
- 测试报告升级为 v0.9，记录本轮 154 项本机测试、类型检查、Lint、完整构建、三角色统一演示账号和中英文页面验收；历史 CI/性能/恢复数字单独标注，未冒充本轮重跑。
- 汇报稿升级为 v1.5，保留 15 页模板，逐页按下午改动复核，移除旧 SPORTS 方向的封面、截图和表述，换用原站素材及当前重构页面。
- 代码补齐 CMS 首页模块控制、原站导航、七款原站商品双语主数据、兼容路由、分析事件及旧演示内容安全迁移；后端已有账户、交易、B2B、CMS、媒体、权限、审计等能力继续复用。

## 本轮验证结果

- `npm run lint`：通过。
- `npm run typecheck`：通过。
- `npm test`：29 个测试文件、154 项测试通过。
- `npm run db:seed`：演示数据脚本已核对；三个演示账号统一由 `/login` 进入并使用简单测试密码。最终数据库集成结果以远端 CI 和包内记录为准。
- `npm run build`：Web 53 页与 API 构建通过。
- 中英文原站首页、原站分类兼容路径、旧 `/play` 和 `/dealers/apply` 入口：本机访问通过。

- 真实支付、退款、银行到账、税务票据和物流接口联调。
